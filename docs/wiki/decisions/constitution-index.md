# Constitution Index

## Charter

The project constitution defines mandatory rules across five categories:

- Architecture boundaries
- Testing policy
- Documentation policy
- Security policy
- Dependency policy

See [Constitution Charter](/docs/constitution/charter.md).

## Engineering principles

- Prefer explicit contracts over implicit assumptions.
- Prefer small scoped changes over broad rewrites.
- Prefer existing conventions over new patterns.
- Prefer testable requirements over vague intent.
- Governance documents must not contradict each other.

See [Engineering Principles](/docs/constitution/principles.md).
